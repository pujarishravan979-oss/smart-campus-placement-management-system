# Smart Campus – Placement Management System

A web-based student placement management system with machine learning-based placement prediction.

## Features
- Student registration and management
- Search, edit and delete student records
- Placement eligibility checking
- Machine learning-based placement prediction
- Interactive dashboard with placement statistics
- SQLite database integration

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Pandas
- Scikit-learn
- Joblib

## Machine Learning
A Random Forest Classifier is used to predict student placement status based on academic performance, skills, internships, projects, and other factors.

The model achieved approximately 76.87% accuracy on the test dataset.

## Project Status
Developed as a student project and open to further improvements.
